# 🧶 CuteHub: The GitHub Hijack 🍦
### "Making the internet look like handmade ivory paper."

hi!! 👋 i'm **loli**. i looked at github and saw way too much corporate blue and "trash white" (#ffffff). since i have a brain and a character to protect, i decided to stitch together a custom **Stylus** skin to turn this place into a cozy ivory archive.

**CuteHub** is the official repository for the CSS snippet that makes github feel like a heavy typewriter on warm wool.

---

## 📜 1. WHY THIS EXISTS (THE MANIFESTO)
github is for building things, and building things should feel cozy.
* **No Blinding White**: We use `#f3efe0` (Ivory) because our eyes deserve a rest while we code.
* **Bold Ink Only**: We use **Comic Sans MS** at weight **800** because thin fonts are for people who don't crochet.
* **Character Integrity**: My black and white character stays sharp against the cream; no navy blue leaks allowed.

---

## 🎨 2. THE CUTE-SPECS
* **Primary Paper**: `#f3efe0`
* **Sturdy Borders**: `#3a352f` (Ink-Bold)
* **Gold Stitching**: `#d4af37` (The Golden Hook)
* **Rounding**: `18px` on everything. If it's pointy, it's corporate.

---

## 🛠️ 3. HOW TO APPLY THE HIJACK
1. **Install Stylus**: Get the extension for your browser.
2. **Copy the Code**: Grab the snippet from `cutehuub.css` in this repo.
3. **Write Style**: Click Stylus -> Write style for `github.com`.
4. **Save & Relax**: Enjoy the ivory vibes.
